# Sample MCP Server

A simple Task Manager MCP Server built as a hands-on exercise for the [Build What Agents Want](https://maven.com/emmanuel/build-ai-ready-apis) course.

## How to Build

1. Open [Replit](https://replit.com) and create a new project
2. Attach `requirements.md` to the chat
3. Paste the contents of `replitMCPServerPrompt.md` into the chat
4. Let the agent build it for you
5. Hit Publish to get a public URL
6. Verify in [MCP Debugger](https://mcpdebugger.dev/)
7. Run Evals in [MCPJam](https://app.mcpjam.com/)
